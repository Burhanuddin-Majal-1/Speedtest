Measurement integrity: This is a browser-based estimate, not a substitute for router diagnostics or a native network utility. HTTP request timing includes browser scheduling, TLS/connection reuse, DNS/cache behavior and server response time. DNS timings measure DNS-over-HTTPS request time, not a raw UDP DNS query. Browser JavaScript cannot send ICMP echo requests, read true packet loss, expose your Wi-Fi RSSI/channel, or guarantee the physical link rate. HTTP probe failures are not labelled packet loss. Throughput depends on test-server load, routing, device CPU, browser limits and concurrent traffic.
